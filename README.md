# مذكّر الأذان (Adhan Reminder)

> تطبيق أندرويد لمؤذن واحد، يذكّر بأوقات الصلاة عبر قراءة جدول المواقيت الشهري من صورة، وضبط منبهات دقيقة محلياً على الجهاز.

## ما هو التطبيق؟

«مذكّر الأذان» تطبيق أندرويد أصلي صُمم لمساعدة المؤذن على عدم تفويت وقت الأذان: يقرأ جدول مواقيت الصلاة الشهري من صورة، ويحوّله إلى مواقيت محفوظة على الجهاز، ثم يضبط منبهات دقيقة لكل صلاة، دون الحاجة إلى حساب أو اتصال دائم بالإنترنت.

## ماذا يفعل؟ وأهم الميزات

- **قراءة جدول المواقيت من صورة:** التقاط جدول المواقيت الشهري أو تحميله كصورة، وقراءة أوقات الصلوات منه.
- **منبهات دقيقة محلية:** ضبط منبهات دقيقة لكل صلاة باستخدام `AlarmManager`، بحيث تعمل حتى عند إغلاق التطبيق.
- **لوحة تحكم:** عرض الصلوات القادمة وأوقاتها وحالة المنبهات.
- **إعدادات مرنة:** ضبط الإعدادات وتخصيص التذكير حسب حاجة المؤذن.
- **فحوصات الجهاز:** التحقق من إعدادات الجهاز التي قد تمنع عمل المنبهات (مثل تحسين البطارية) وتنبيه المستخدم إليها.
- **نسخ احتياطي:** حفظ نسخة احتياطية من البيانات والإعدادات واستعادتها.
- **يعمل دون اتصال:** بعد قراءة الجدول، لا يحتاج التطبيق إلى الإنترنت لعرض المواقيت وضبط المنبهات.

## كيفية الاستخدام

1. ثبّت التطبيق على جهاز أندرويد.
2. أدخل جدول مواقيت الصلاة الشهري عن طريق التقاط صورته أو تحميلها.
3. راجع الأوقات المقروءة وتأكد من صحتها.
4. فعّل المنبهات للصلوات المطلوبة، وامنح التطبيق الأذونات اللازمة للتنبيه الدقيق وتجاوز تحسين البطارية عند الحاجة.
5. سيذكّرك التطبيق بكل صلاة في وقتها.

للمؤذن دليل خاص في مجلد الوثائق: `docs/دليل-المؤذن.md`.

## التقنيات المستخدمة

- **اللغة والواجهة:** Kotlin وJetpack Compose
- **التخزين:** Room لقاعدة البيانات المحلية، وPreferences DataStore للإعدادات
- **المنبهات:** AlarmManager للمنبهات الدقيقة
- **الحد الأدنى للنسخة المدعومة:** Android 12 / API 31، وحزمة التطبيق `com.adhanreminder.app`
- **البناء:** Gradle (باستخدام Kotlin DSL)

## البناء

ثبّت JDK 17 أو أحدث، وAndroid SDK Platform 36 وBuild Tools 35.0.0، ثم شغّل:

```bash
./gradlew assembleDebug
```

سيظهر APK في `app/build/outputs/apk/debug/app-debug.apk`.

## الاختبارات

```bash
./gradlew test
```

## الإصدار والتوقيع

لا تُنشئ مفتاح الإنتاج داخل هذا المشروع. أنشئه على جهاز المالك عبر `scripts/create_keystore.sh`، ثم أنشئ ملفاً محلياً غير متتبّع باسم `keystore.properties` يحتوي `storeFile` و`storePassword` و`keyAlias` و`keyPassword`. بعد ذلك شغّل:

```bash
./scripts/build_release.sh
```

للتحقق اليدوي:

```bash
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

## الخصوصية

بيانات الجدول والإعدادات محلية. الاتصال بالشبكة يُستخدم فقط عند قراءة صورة الجدول. لا يوجد Firebase أو تحليلات أو إعلانات أو تسجيل دخول أو إرسال سجلات عن بُعد، ولا يُسجَّل مفتاح API أو محتوى الصورة أو نص استجابة النموذج.
